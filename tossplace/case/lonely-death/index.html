01 프로젝트 개요

재현율 기준의 고독사 판별 모델 개발과 검수량 분석

고독사 판별 모델을 개발하고, 모델별 성능 차이와 실제 업무 적용 가능성을 검토했습니다. 균형 표본에서 정한 변수와 모델을 57,145건 전체 데이터에서 다시 검증하고, 고독사 사례를 놓치지 않으면서 담당자의 검수 부담을 줄일 수 있는 기준을 분석했습니다.

  1. 01문제

    고독사 통계를 내려면 담당자가 변사 사건마다 사건개요 글을 읽고 판정해야 했습니다. 2024년 변사 사건 57,145건 가운데 고독사는 3,924건(6.9%)이었고, 건당 약 30분이 들었으며 같은 사건을 담당자마다 다르게 판정하기도 했습니다.

  2. 02목표

    정확도 대신 재현율을 우선 지표로 두고, 정해 둔 재현율을 지키면서 사람이 검수할 사례를 최소화하는 이진 분류로 문제를 다시 정의했습니다. 판정에는 담당자가 확인할 수 있는 근거를 붙이기로 했습니다.

  3. 03설계

    현장 담당자 인터뷰로 판단 기준을 모아 파생변수 45개를 정했습니다(원시 변수 22개와 합쳐 67개). 같은 입력에서 LightGBM이 BERT보다 모든 지표에서 앞서 판정 모델로 정했고, SHAP 상위 18개 변수로 줄여도 성능이 거의 유지됐습니다.

  4. 04검증

    57,145건을 학습 70% · 검증 15% · 테스트 15%로 나누고, 목표 재현율에 맞는 기준값을 검증 데이터에서 고른 뒤 테스트 데이터에서 다시 측정했습니다.

  5. 05결과

    목표 재현율 95%에서 테스트 재현율은 96.77%, 사람이 볼 사례는 13.8%(57,145건 중 7,886건)였습니다. 테스트 정밀도는 48.35%라 검수 대상의 절반 가까이는 고독사가 아닙니다. 모두 오프라인 테스트 결과입니다.

03 과정

자세한 이야기

프로젝트 배경

고독사 통계를 내려면 담당자가 변사 사건마다 사건개요 글을 읽고 고독사인지 판정해야 합니다. 2024년 변사 사건은 57,145건이었고, 이 가운데 고독사는 3,924건(6.9%)이었습니다. 고독사를 놓치지 않으려면 나머지 사건도 모두 읽어야 했습니다. 건당 약 30분이 들었고, 같은 사건을 담당자마다 다르게 판정하기도 했습니다.

2025년 11월부터 2026년 1월까지 공공기관 공동연구로 변사 사건 기록에서 고독사를 판별하는 모델을 PoC로 만들었습니다. 저는 전처리, 파생변수 설계, 모델 비교와 성능 평가, 재현율 기준 설계와 판별 화면 구현을 맡았습니다. 데이터는 기관 내부망 밖으로 나갈 수 없었습니다.

문제 재정의

고독사는 전체 사건의 6.9%뿐이라, 정확도가 높더라도 고독사를 얼마나 놓치는지는 따로 확인해야 했습니다. 실무자와 기관에서도 같은 기준을 이야기했습니다.

“고독사는 절대 놓치면 안 된다.”

그래서 정확도 대신 재현율을 우선 지표로 두고, 정해 둔 재현율을 지키면서 사람이 검수할 사례를 최소화하는 이진 분류로 문제를 다시 정의했습니다. 판정에는 담당자가 확인할 수 있는 근거를 함께 붙이기로 했습니다.

  • 재현율 — 실제 고독사 가운데 모델이 고독사로 잡아낸 비율입니다. 우선 지표로 두었습니다.
  • 정밀도 — 모델이 고독사로 판정한 사례 가운데 실제 고독사의 비율입니다. 정밀도가 낮은 만큼 사람이 검수에서 걸러야 합니다.
  • 검수량 — 사람이 직접 읽어야 하는 사례의 양입니다. 재현율을 지키는 범위에서 줄이는 것을 목표로 했습니다.

데이터 구성과 실험 단계

데이터는 세 단계로 다뤘습니다. 원시 변사 데이터 57,145건(원시 변수 22개)에서 시작해, 비식별 환경에서 균형 표본 600건과 1,000건을 뽑아 변수와 모델을 정했습니다. 마지막에는 다시 57,145건 전체로 돌아가 검증했습니다.

실험은 탐색, 변수 설계, 정밀 검증, 실전 검증의 4단계로 나눠 모두 13회 진행했습니다.

파생변수 설계

사건개요는 자유 텍스트입니다. 글을 그대로 모델에 넣는 대신, 담당자가 판정할 때 보는 기준을 변수로 만들었습니다. 현장 담당자 인터뷰로 판단 기준을 모으고, 60개가 넘는 후보 가운데 파생변수 45개를 정했습니다.

  • 원시 변수 — 22개
  • 파생변수 — 45개(독거 여부 · 최초 발견자 · 발견 계기 · 발견 경과일 등)
  • 모델 입력 — 원시 변수와 파생변수를 합친 67개

판정 모델 비교

같은 입력으로 LightGBM과 BERT를 비교했습니다. 균형 표본에서 진행한 실험이며, LightGBM이 모든 지표에서 앞섰습니다.

  • 재현율 — LightGBM 0.990, BERT 0.960
  • F1 — LightGBM 0.942, BERT 0.922
  • ROC-AUC — LightGBM 0.988, BERT 0.963
  • 학습 시간 — LightGBM 수 분, BERT 수 시간
  • 판정 근거 설명 — LightGBM은 SHAP으로 건별 제시, BERT는 어려움

사건개요의 내용이 이미 파생변수로 정리돼 있어, BERT의 문맥 이해가 더 보탤 것이 없었습니다.

그래서 판정 모델은 LightGBM으로 정했습니다. 성능이 더 높고, 학습이 수 분이면 끝나며, 판정마다 어떤 변수가 영향을 줬는지 SHAP으로 보여 줄 수 있기 때문입니다. BERT는 판정 대신 사건개요에서 핵심 변수를 뽑는 일에 쓰고, 검토자가 읽을 판단 사유는 규칙과 LLM으로 만들도록 역할을 나눴습니다.

  • 판정 — LightGBM
  • 핵심 변수 추출 — BERT(BigBird)가 사건개요에서 뽑습니다.
  • 판단 사유(참고 설명) — 규칙과 LLM(Gemma 3)이 검토자용으로 씁니다. 판정은 LightGBM이 하고, 이 설명은 검토를 돕는 참고 자료입니다.

변수 축소

SHAP 상위 변수만 남겨 67개를 18개로 줄여도 판별 성능은 거의 그대로였습니다.

  • 재현율 — 67개 0.990, 18개 0.970
  • F1 — 67개 0.942, 18개 0.932
  • 정밀도 — 67개 0.899, 18개 0.897

상위 변수 대부분은 파생변수였습니다(최종 생활반응에서 발견까지 · 최초 발견자 · 발견 계기 · 부패 여부 등). 핵심 변수만 자동으로 뽑으면 되므로, 사건개요에서 변수를 뽑는 BERT의 부담도 줄었습니다.

재현율 기준에 따른 검수량 분석

변수와 모델은 균형 표본에서 정했지만, 판별 기준은 57,145건 전체에서 정했습니다. 57,145건을 학습 70% · 검증 15% · 테스트 15%로 나누고, 목표 재현율마다 기준값을 검증 데이터에서 고른 뒤 테스트 데이터에서 다시 측정했습니다. 아래 표의 목표는 목표 재현율(%)입니다.

목표 재현율 95%에서 기준값은 0.3208이었고, 검증 재현율 95.08%, 테스트 재현율 96.77%로 목표가 테스트 데이터에서도 유지됐습니다. 이때 사람이 볼 사례는 13.8%(57,145건 중 7,886건)였습니다.

목표를 낮출수록 사람이 볼 양은 줄고 놓칠 위험은 커집니다. 목표를 99%로 올리면 사람이 볼 비율은 28.0%로 늘고, 90%로 낮추면 10.6%로 줄지만 테스트 재현율은 92.19%가 됩니다. 그래서 기준값 하나만 정하지 않고, 목표 재현율별 기준값과 검수량을 함께 정리했습니다.

이 수치는 2024년 사건 데이터를 나눠 측정한 오프라인 테스트 결과이며, 실제 업무에 적용해 측정한 값은 아닙니다.

판별 화면

판정마다 확률과 판단 사유를 붙이고, 확률이 높은 사례는 자동 승인, 중간 구간은 검수, 낮은 사례는 자동 제외로 나눴습니다. 담당자가 목표 재현율을 바꾸면 기준값과 검수량이 함께 바뀝니다.

데이터가 기관 내부망 밖으로 나갈 수 없어, 담당자 PC 안에서 실행하는 로컬 웹 애플리케이션(Flask + React)으로 만들었습니다. 사례 엑셀 파일을 올리면 판정과 확률이 나옵니다. 글 머리의 화면처럼 파일 선택, 전처리, 파생변수 생성, 분류 실행, 직접 검수의 순서로 진행하고, 결과는 엑셀로 저장합니다.

  • 정밀도 — 목표 재현율 95%에서 테스트 정밀도는 48.35%입니다. 검수 대상의 절반 가까이는 고독사가 아니므로, 사람이 마지막에 확인하는 구조가 필요합니다.

  • 다음 단계 제안 — 사후 판별에서 사전 예방으로 범위를 넓혀, 복지 서비스 이탈 · 안부 응답 부재 같은 신호를 같은 파생변수 구조로 위험 점수화하는 방향을 제안했습니다.

프로젝트를 마치며

이번 프로젝트에서는 고독사 판별을 정확도가 아니라 재현율과 검수량의 문제로 다시 정의하고, 현장 기준으로 만든 파생변수와 LightGBM으로 판정 모델을 구성했습니다. 목표 재현율 95%에서 테스트 재현율 96.77%, 사람이 볼 비율 13.8%를 확인했지만, 정밀도가 48.35%라 사람의 확인은 여전히 필요합니다.

모델의 성능 수치가 담당자가 볼 사례 수로 어떻게 바뀌는지까지 정리해야 업무 기준으로 쓸 수 있다는 점을 경험했습니다.
