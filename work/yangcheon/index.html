01

양천구청 AI 민원창구

민원인이 말하면 상담 기록과 서식이 채워지는 창구

기간
2025 · 1차 실증 → 2차 실증
맡은 일
음성 인식 · 화자 분리 담당
함께한 곳
양천구청 · 동국대학교 지산학 공동연구
쓴 기술
Whisper 파인튜닝 · Pyannote · RNNoise · VAD · 의도 분류

01

문제 정의

주어진 문제민원 상담을 음성으로 인식해 요약하고 서식까지 채우는 시스템을 만든다.

기능을 만드는 게 아니라 반복되는 민원 기록 업무가 실제로 줄어드는지 보여야 했어요. 그러려면 개발팀이 설계한 흐름과 공무원이 일하는 방식 사이의 간극부터 메워야 했어요.

02

동작 구조

  1. 01민원인 발화
  2. 02음성 인식제가 맡은 부분
  3. 03화자 분리제가 맡은 부분
  4. 04민원 · 일반 구분
  5. 05요약 · 서식 작성
  6. 06공무원 확인

03

내 판단

  1. 01

    현장에 직접 들어갔어요

    공무원 인터뷰와 실무회의에 참여해 민원이 처리되는 과정을 확인했어요. 음성 인식과 화자 분리는 그 자리에서 직접 시연했어요.

  2. 02

    말로 나온 요구를 개발 항목으로 바꿨어요

    민감정보 처리와 화자 구분과 요약 방식처럼 회의에서 나온 요구를 개발 항목과 후속 조치로 정리해 팀과 나눴어요.

  3. 03

    1차 실증 피드백을 유형으로 묶었어요

    피드백을 유형별로 나눠 팀과 함께 대응했어요. 행정·법률 용어로 음성 인식 모델을 다시 학습시키고 무음 감지 기준을 조정했어요. 구청 소음으로 잡음 제거와 데이터 증강을 하고 실시간 화자 분리를 붙였어요. 민원 발화와 일반 발화를 구분하는 분류 모델과 민원 유형별 요약 템플릿도 만들고 장비별 설정값을 찾았어요.

04

결과

Before

민원인의 말을 공무원이 듣고 서식에 직접 옮겨 적었어요. 개발팀이 설계한 흐름은 실제 창구 업무와 어긋나 있었어요.

→

제가 한 것

  • 실무회의 참여와 현장 시연으로 요구를 개발 항목으로 정리
  • 행정 · 법률 용어 재학습, 구청 소음 기반 잡음 제거, 실시간 화자 분리
  • 민원 · 일반 발화 구분과 민원 유형별 요약 템플릿
→

After

  • 민원인이 말하면 요약과 서식 초안이 채워지고 공무원이 확인하는 창구 흐름
  • 공무원 시뮬레이션 상담으로 1차 실증 완료
  • 양천구청 민원여권과 창구에서 실제 민원인 대상 2차 실증

05

배운 것

성능 숫자가 좋아도 현장 조건이 다르면 쓰이지 않아요.
