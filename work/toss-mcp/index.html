03 내 판단

이렇게 판단하고 움직였어요

01

기본은 가짜로 두고 한 단계씩만 열었어요

가짜 모드에서 조회 연결과 실주문까지 환경변수로 하나씩 열어요. 실주문 도구는 새 인자를 받지 않고 플랜이 발급한 토큰과 사람이 다시 입력한 확인 문구가 모두 맞아야만 나가요. 킬스위치 하나로 전부 가짜 모드로 내려가요.

02

얇은 API 래퍼 대신 판단 단위로 도구를 묶었어요

시세와 캔들과 지표와 유의사항을 한 번에 합쳐 LLM이 한 번의 호출로 판단할 수 있게 했어요. 위험한 쓰기 도구는 최소로 남겼어요.

03

감이 아니라 규칙으로 사고팔게 했어요

변동성에 반비례해 포지션 크기를 정하고 변동성에 맞춰 목표가를 잡아요. 거래 기록을 원장으로 손익을 다시 계산하고 청산 우선순위를 코드로 못 박았어요.

04

검증을 자산으로 남겼어요

실주문 경로는 반증부터 찾는 리뷰를 통과해야 합쳤고 회귀는 유닛 테스트로 잠갔어요. 코드보다 스펙 문서를 먼저 합의했어요.
