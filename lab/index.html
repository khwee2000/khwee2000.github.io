01

내 컴퓨터를 위해 만든 것

매일 반복하던 일을 한 번에 끝내려고 만든 macOS 도구들이에요. 공개한 한컴단축키와 Claude Usage Widget도 여기서 시작했어요.

로컬 전용2026.05macOS 메뉴바 위젯

노션투두

회사 위클리 TODO를 노션 대신 메뉴바에서 보고, 입력하고, 주간 업데이트까지 돌려요.

  • Swift 5.9 · SwiftUI MenuBarExtra · Universal Binary · Developer ID 서명
  • LLM이 필요한 작업은 API 대신 Claude Code CLI를 subprocess로 호출해요
  • 단위 테스트 86개 · 콜드 런치 0.11초 · 대기 CPU 0%

Swift · SwiftUI · Notion REST API · XcodeGen

로컬 전용2026.06macOS 앱 · DMG

샷정리

바탕화면에 쌓인 스크린샷을 읽고, 내용에 맞는 한글 이름을 붙이고, 카테고리와 날짜 폴더로 정리해요.

  • Apple Vision 온디바이스 OCR, 추출한 텍스트만 로컬 Claude CLI에 넘겨요 — 이미지는 어디에도 올라가지 않아요
  • Dry-run 미리보기 → 적용 → 되돌리기, 폴더 자동 감시(FSEvents)
  • 실제 바탕화면 102장으로 스캔과 미리보기까지 실측

Swift · SwiftUI · Vision · 서명된 DMG

완성 · 로컬2026.07Swift CLI + 스킬

nukkishot

“캡처해줘” 한마디면 화면 캡처부터 배경 제거, 여백 자르기, 클립보드 복사까지 한 번에 끝나요.

  • 기본은 macOS Vision 피사체 마스크로 1초 안에, 머리카락 같은 경계는 Nukki Studio로 넘겨요
  • 피사체를 못 찾는 평면 UI 캡처는 단색 여백만 자동으로 잘라요
  • Claude Code 스킬이 자연어를 플래그로 바꿔 줘요

Swift(단일 파일) · Vision · Claude Code 스킬

로컬 웹앱2026.06공개한 Nukki의 고화질 형

Nukki Studio

브라우저 안에서 도는 Nukki로는 부족한 머리카락 경계를, 로컬 GPU에서 다섯 단계로 살려요.

  • 세그먼트 → 트라이맵 → 알파 매팅 → 경계 정렬 → 색 번짐 제거 파이프라인
  • 처리할 때마다 GPU 메모리를 비워 요청이 쌓여도 속도가 유지돼요
  • 누끼 결과를 그라데이션 · 단색 · 투명 배경에 여백과 그림자로 합성해 내려받아요

Python · FastAPI · PyTorch MPS · BiRefNet · ViTMatte

진행 중2026.06iPhone 앱 + Mac 에이전트

ClaudeTap

Claude Code가 “실행할까요?” 하고 물을 때, 컴퓨터 앞에 없어도 iPhone에서 승인하거나 거부해요.

  • PreToolUse 훅(bash + curl) → Mac 로컬 에이전트(Node, 의존성 0) → iOS 앱(SwiftUI)
  • 에이전트가 꺼져 있으면 원래 프롬프트로 조용히 돌아가요
  • 1단계 폴링 방식으로 종단 시연 완료, 2단계 푸시 알림과 Tailscale 연결은 예정

Node.js · Swift · SwiftUI · Claude Code hooks

서비스로 실험해 본 것

사람들에게 내놓을 생각으로 만들었지만 아직 공개 전이거나, 데모 단계에 있는 것들이에요.

로컬 · 정적 웹앱2026.07만세력 엔진 포함

SAJU OS와 만세력 엔진

사주를 보는 앱이 아니라 내 인생을 기록하고 이해하는 플랫폼 — 계산은 결정론 엔진이, 해석만 LLM이 맡아요.

  • 24절기를 천문 공식으로 직접 계산하고 Python과 JS 두 엔진을 같은 결과로 동기화해요 — 검증 픽스처 31항목 전부 일치
  • 원국 · 인생 복기 · 가족 · 심리 비교 · 출생시간 추정까지 8화면, 외부 API 없이 브라우저에서 동작
  • 같은 엔진 계보가 공개 서비스 언니의 비밀에 들어갔어요

Python · JavaScript(ES 모듈) · 자체 호스팅 폰트

비공개 운영2026.09Python · 대시보드

쓰레드 발행기

글을 올리는 코드보다 계정을 지키는 가드가 핵심인 Threads 자동 발행 도구예요.

  • 공식 Threads API만 써요 — 브라우저 자동화와 비공식 API는 약관 위반이라 처음부터 배제했어요
  • 계정 나이에 따라 발행 수를 늘리고, 최근 30개 글과 유사도 0.72 이상이면 막고, 외부 링크 비율을 경고해요
  • 승인 큐 → 발행 → 성과 확인까지 한 대시보드에서

Python · Threads API · 유사도 게이트

개인용2026.06toss-mcp의 전신

  • 서버는 파이썬 표준 라이브러리만으로, 데이터는 무료 차트 API로 — 설치 없이 바로 떠요
  • 단타와 장기 모드에 따라 지표와 매매 시나리오 계산식이 바뀌어요
  • 여기서 만든 RSI · 단타 점수 로직이 그대로 toss-mcp로 옮겨갔어요

Python · 바닐라 JS

비공개2026.07Chrome 확장 + 하네스

케어투데이 글쓰기 패널

요양원 · 시니어 건강 정보 블로그를 위한 Chrome 확장이에요. 네이버 글쓰기 화면 옆에 붙어 초안부터 발행 패키지까지 만들어요.

  • 자동 발행은 약관 위반이라 패키지까지만 만들고 발행은 사람이 해요
  • 의료 표방 · 유료 시설 유인 · 가짜 후기를 조항 단위로 걸러내는 컴플라이언스 게이트
  • 건보공단 공공데이터로 서울 요양원 480곳 백로그를 만들어 글감으로 써요
